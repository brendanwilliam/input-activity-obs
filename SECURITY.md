# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting form](https://github.com/brendanwilliam/input-activity-obs/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include affected versions, reproduction steps, impact, and any proposed mitigation. We will acknowledge reports promptly and coordinate a fix and disclosure timeline with you.

## Sensitive input

This plugin observes local input only after macOS Accessibility permission is granted. Reports involving accidental keystroke logging, disclosure, or permission handling are security-sensitive.
